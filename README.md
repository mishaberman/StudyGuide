# API and developer education study labs

Hands-on, AI-assisted practice projects with synthetic data, setup instructions, and explicit verification notes.

| Project | Contents | Start here |
|---|---|---|
| OpenAI API labs | 20 Python exercises: parsing, metrics, Responses API, structured output, tools and Agents SDK | [OpenAI README](openai-api-labs/README.md) |
| Claude Platform labs | 10 Python labs: Messages API, tools, evaluation, MCP, reliability and teaching workflows | [Claude README](claude-platform-labs/README.md) |

For VS Code, open the individual project folder so its launch configurations and relative paths work. Each project has its own dependencies and MIT license. Use separate virtual environments.

Offline/local checks were completed during preparation. Live API calls require your own credentials, explicit opt-in and available model access; they incur API charges. See each project's `VERIFICATION.md` for the limits of testing.

These are independent educational projects, not official vendor courses or a claim of production deployment. Private recruiter instructions, personal interview notes and employer material are not included in the newly added lab directories.

Existing HTML study guides remain in the repository. The project-level licenses apply to the new lab directories; they do not change licensing of pre-existing material.
